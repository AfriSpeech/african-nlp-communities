## Pan-African

| Community | GitHub | Description |
| :-- | :-- | :-- |
| Masakhane | [masakhane-io](https://github.com/masakhane-io) | Grassroots NLP community. 4,000+ members across 48 countries. Machine translation, NER, QA, POS tagging, TTS for 48 languages. |
| Lanfrica | [lanfrica](https://github.com/lanfrica) | Cataloging all African AI resources — datasets, models, papers, policies across 2,199 languages. |
| Zindi Africa | [zindiafrica](https://github.com/zindiafrica) | Africa's data science competition platform. Hosts NLP challenges for African languages. |
| Lelapa AI | [Lelapa-AI](https://github.com/Lelapa-AI) | Language AI startup. Vulavula API (NER, sentiment, MT, ASR, TTS), InkubaLM. 13+ languages. |
| AfriSpeech | [AfriSpeech](https://github.com/AfriSpeech) | Speech data corpus builder for 693 African languages. ASR, TTS, language identification. |
| AfriNLP | [AfriNLP](https://github.com/AfriNLP) | Research org focused on efficient translation models for African languages. |
| LocaleNLP | [LocaleNLP](https://github.com/LocaleNLP) | NLP models for low-resource African languages. AfriLION, Darija translation. Based in Morocco. |
| Deep Learning Indaba | [deeplearningindaba.com](https://deeplearningindaba.com) | Annual ML conference + 47 IndabaX country chapters. Capacity building across Africa. |
